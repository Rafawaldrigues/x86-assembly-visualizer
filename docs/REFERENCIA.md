source. GAS/AT&T reverses the order and prefixes registers with `%`.

## Category: Data movement

Copies values between registers, memory and immediates.

### MOV — copies a value

**Syntax:** `MOV destination, source`

Copies the contents of the source to the destination. The source does not change. There is no memory-to-memory MOV: one of the two sides must be a register (or the source an immediate).

```asm
MOV RAX, 10        ; puts the number 10 into RAX
MOV RBX, RAX       ; copies RAX into RBX
MOV [counter], EAX ; writes EAX to the variable counter
```

**Flags:** Does not change flags.

### MOVZX — copies filling with zeros

**Syntax:** `MOVZX larger_destination, smaller_source`

Copies a small value (8 or 16 bits) into a larger register, filling the rest with zeros. Use it for unsigned values.

```asm
MOVZX EAX, BYTE [buf]  ; 1 byte -> 32 bits, rest zeroed
```

**Flags:** Does not change flags.

### MOVSX — copies preserving the sign

**Syntax:** `MOVSX larger_destination, smaller_source`

Same as MOVZX, but replicates the sign bit. Use it for signed values, otherwise -1 in 8 bits becomes 255 in 32 bits.

```asm
MOVSX RAX, AL      ; -1 stays -1
```

**Flags:** Does not change flags.

### MOVSXD — 32 to 64 bits with sign

**Syntax:** `MOVSXD destination64, source32`

Sign-extends a 32-bit value to 64 bits. Very common when an int index is used as a pointer offset.

```asm
MOVSXD RCX, EDI
```

**Flags:** Does not change flags.

### LEA — computes an address

**Syntax:** `LEA destination, [expression]`

Computes the address of the expression inside the brackets and stores the number in the destination, WITHOUT reading memory. It is the normal way to take the address of a string, and also a fast way to do arithmetic (multiply by 2/4/8 and add).

```asm
LEA RSI, [msg]            ; RSI = address of the string
LEA RAX, [RBX+RCX*4+8]    ; RAX = RBX + RCX*4 + 8, without touching memory
```

**Flags:** Does not change flags.

> **Note:** MOV RSI, [msg] would read the contents. LEA takes the address.

### XCHG — swaps two values

**Syntax:** `XCHG a, b`

Swaps the contents of the two operands. When one of them is memory, the operation is atomic (it locks the bus).

```asm
XCHG RAX, RBX
```

**Flags:** Does not change flags.

### CMOV — copies only when the condition is true

**Syntax:** `CMOVcc destination, source`

Copies the source to the destination only when the condition holds (the same suffix family as the jumps: E, NE, G, L, A, B...). It avoids a branch, which helps the processor not to mispredict.

```asm
CMP RAX, RBX
CMOVL RAX, RBX   ; RAX = min(RAX, RBX)
```

**Flags:** Reads the flags, does not change them.

### CMOVE — Conditional Move if E

**Syntax:** `CMOVE destination, source`

Copies the source to the destination only when equal (ZF = 1). No branch, so there is no risk of a misprediction.

```asm
CMP RAX, RBX
CMOVE RAX, RBX
```

**Flags:** Reads the flags, does not change them.

### CMOVZ — Conditional Move if Z

## Category: Stack

Pushes/pops values and maintains the function frame.

### PUSH — pushes a value onto the stack

**Syntax:** `PUSH source`

Subtracts 8 from RSP and writes the 64-bit value at that address. The stack grows toward LOWER addresses.

```asm
PUSH RAX        ; saves RAX on the stack
PUSH QWORD 42
```

**Flags:** Does not change flags.

### POP — pops a value off the stack

**Syntax:** `POP destination`

Reads 8 bytes from the top of the stack into the destination and adds 8 to RSP. Every PUSH needs a matching POP (or an RSP adjustment) before the RET.

```asm
POP RBX
```

**Flags:** Does not change flags.

### ENTER — builds the stack frame

**Syntax:** `ENTER size, level`

Equivalent to PUSH RBP / MOV RBP, RSP / SUB RSP, size. Rarely used today: the hand-written sequence is faster.

```asm
ENTER 32, 0
```

**Flags:** Does not change flags.

### LEAVE — tears down the stack frame

**Syntax:** `LEAVE`

Equivalent to MOV RSP, RBP / POP RBP. It is the standard epilogue of a function that used RBP.

```asm
LEAVE
RET
```

**Flags:** Does not change flags.

## Category: Arithmetic

Adds, subtracts, multiplies, divides.

### ADD — adds

**Syntax:** `ADD destination, source`

destination = destination + source.

```asm
ADD RAX, 1
ADD RAX, RBX
```

**Flags:** Changes CF, OF, SF, ZF, AF, PF.

### ADC — adds with the carry-in

**Syntax:** `ADC destination, source`

destination = destination + source + CF. Used to add numbers wider than 64 bits in parts.

```asm
ADD RAX, RCX
ADC RDX, RBX
```

**Flags:** Changes CF, OF, SF, ZF, AF, PF.

### SUB — subtracts

**Syntax:** `SUB destination, source`

destination = destination - source. It is also how stack space is reserved: SUB RSP, 32.

```asm
SUB RAX, 5
SUB RSP, 32   ; opens 32 bytes of local space
```

**Flags:** Changes CF, OF, SF, ZF, AF, PF.

### SBB — subtracts with the borrow

**Syntax:** `SBB destination, source`

destination = destination - source - CF. The counterpart of ADC for long numbers.

```asm
SBB RDX, RBX
```

**Flags:** Changes CF, OF, SF, ZF, AF, PF.

### INC — adds 1

**Syntax:** `INC destination`

destination = destination + 1. It does not touch CF (unlike ADD x, 1).

```asm
INC RCX
```

**Flags:** Changes OF, SF, ZF, AF, PF. Preserves CF.

### DEC — subtracts 1

**Syntax:** `DEC destination`

destination = destination - 1. Widely used in loop counters together with JNZ.

```asm
DEC RCX
JNZ loop
```

**Flags:** Changes OF, SF, ZF, AF, PF. Preserves CF.

### NEG — flips the sign

**Syntax:** `NEG destination`

destination = 0 - destination (two's complement).

```asm
NEG RAX
```

**Flags:** Changes CF, OF, SF, ZF, AF, PF.

### MUL — Multiply (unsigned)

**Syntax:** `MUL source`

Multiplies RAX by the source. The 128-bit result lands in RDX:RAX. The implicit RAX operand is mandatory.

```asm
MOV RAX, 6
MOV RBX, 7
MUL RBX      ; RAX = 42
```

**Flags:** Changes CF and OF (they tell whether the high part is nonzero).

### IMUL — Integer Multiply (signed)

**Syntax:** `IMUL source  |  IMUL dest, source  |  IMUL dest, source, immediate`

Signed multiplication. The two- or three-operand form is the one used day to day, because the destination is explicit.

```asm
IMUL RAX, RBX
IMUL RAX, RBX, 4
```

**Flags:** Changes CF and OF.

### DIV — Divide (unsigned)

**Syntax:** `DIV divisor`

Divides RDX:RAX by the divisor. The quotient goes to RAX and the remainder to RDX. WARNING: clear RDX first (XOR RDX, RDX), otherwise the result is garbage or the CPU raises an exception.

```asm
XOR RDX, RDX
MOV RAX, 100
MOV RBX, 7
DIV RBX      ; RAX=14, RDX=2
```

**Flags:** Flags are undefined.

### IDIV — Integer Divide (signed)

**Syntax:** `IDIV divisor`

Same as DIV, but signed. Before it, use CQO (64 bits) or CDQ (32 bits) to sign-extend into RDX/EDX.

```asm
MOV RAX, -100
CQO
IDIV RBX
```

**Flags:** Flags are undefined.

## Category: Logic and bits

AND/OR/XOR/NOT and shifts.

### AND — bitwise AND

**Syntax:** `AND destination, source`

Keeps only the bits that are set in both operands. Used to mask (keep just part of the value).

```asm
AND RAX, 0x0F     ; keeps only the low 4 bits
```

**Flags:** Clears CF and OF; changes SF, ZF, PF.

### OR — bitwise OR

**Syntax:** `OR destination, source`

Turns on in the destination every bit that is set in the source. Used to set flags.

```asm
OR RAX, 1         ; sets bit 0
```

**Flags:** Clears CF and OF; changes SF, ZF, PF.

### XOR — exclusive OR

**Syntax:** `XOR destination, source`

A bit is 1 when the two are different. XOR of a register with itself is the idiomatic (and shortest) way to zero it.

```asm
XOR RAX, RAX      ; RAX = 0
```

**Flags:** Clears CF and OF; changes SF, ZF, PF.

### NOT — inverts every bit

**Syntax:** `NOT destination`

One's complement: every 0 becomes 1 and vice versa.

```asm
NOT RAX
```

**Flags:** Does not change flags.

### SHL — shifts bits to the left

**Syntax:** `SHL destination, count`

Each shift by 1 multiplies by 2. Zeros come in from the right.

```asm
SHL RAX, 3        ; RAX = RAX * 8
```

**Flags:** Changes CF (the last bit shifted out), OF, SF, ZF, PF.

### SAL — identical to SHL

**Syntax:** `SAL destination, count`

The same instruction as SHL; it exists only for symmetry with SAR.

```asm
SAL RAX, 1
```

**Flags:** Same as SHL.

### SHR — Shift Right (unsigned)

**Syntax:** `SHR destination, count`

Shifts right bringing in zeros. It is the same as dividing unsigned values by 2^n.

```asm
SHR RAX, 1        ; RAX = RAX / 2 (unsigned)
```

**Flags:** Changes CF, OF, SF, ZF, PF.

### SAR — Shift Arithmetic Right (signed)

**Syntax:** `SAR destination, count`

Shifts right repeating the sign bit, so negative numbers stay negative.

```asm
SAR RAX, 2
```

**Flags:** Changes CF, OF, SF, ZF, PF.

### ROL — rotates to the left

**Syntax:** `ROL destination, count`

The bits that leave one side enter the other. Nothing is lost.

```asm
ROL AL, 4
```

**Flags:** Changes CF and OF.

### ROR — rotates to the right

**Syntax:** `ROR destination, count`

Rotation in the opposite direction of ROL.

```asm
ROR AL, 4
```

**Flags:** Changes CF and OF.

### BT — tests a bit

**Syntax:** `BT value, index`

Copies the selected bit into CF without changing the value.

```asm
BT RAX, 5
JC enabled
```

**Flags:** Changes CF.

## Category: Comparison

Computes and discards the result, keeping only the flags.

### CMP — compares two values

**Syntax:** `CMP a, b`

Computes a - b, throws the result away and keeps only the flags. It is always read together with the following branch: CMP RAX, 10 + JG means "if RAX > 10".

```asm
CMP RAX, 10
JG bigger
```

**Flags:** Changes CF, OF, SF, ZF, AF, PF.

### TEST — an AND that only produces flags

**Syntax:** `TEST a, b`

Computes a AND b and keeps only the flags. TEST RAX, RAX is the idiomatic way to ask "is RAX zero?" — shorter than CMP RAX, 0.

```asm
TEST RAX, RAX
JZ was_zero
```

**Flags:** Clears CF and OF; changes SF, ZF, PF.

### SET — becomes 0 or 1 according to the condition

**Syntax:** `SETcc destination8`

Writes 1 into the destination byte if the condition is true, otherwise 0. This is how compilers produce a bool.

```asm
CMP RAX, RBX
SETE AL     ; AL = (RAX == RBX)
```

**Flags:** Reads the flags, does not change them.

### SETE — 1 when equal

**Syntax:** `SETE destination8`

Puts 1 in the destination byte when equal (ZF = 1), otherwise 0.


**Flags:** Reads the flags, does not change them.

## Category: Branch

Changes the flow of execution.

### JMP — unconditional branch

**Syntax:** `JMP destination`

Continues execution at the given label (or address), with no condition and no return address saved.

```asm
JMP done
```

**Flags:** Does not change flags.

### LOOP — repeats using RCX as the counter

**Syntax:** `LOOP label`

Decrements RCX and branches if RCX != 0. Equivalent to DEC RCX / JNZ, but it is usually slower than writing the two.

```asm
MOV RCX, 5
body:
  LOOP body
```

**Flags:** Does not change flags.

### JE — branches when equal

**Syntax:** `JE label`

Branches to the label when the last comparison indicated equal. Flag condition: ZF = 1. When the condition is false, execution simply falls through to the next line.

```asm
CMP RAX, RBX
JE target
```

**Flags:** Reads the flags, does not change them.

### JZ — branches when zero

**Syntax:** `JZ label`

Branches to the label when the last comparison indicated zero. Flag condition: ZF = 1. When the condition is false, execution simply falls through to the next line.

```asm
CMP RAX, RBX
JZ target
```

**Flags:** Reads the flags, does not change them.

### JNE — branches when not equal

**Syntax:** `JNE label`

Branches to the label when the last comparison indicated not equal. Flag condition: ZF = 0. When the condition is false, execution simply falls through to the next line.

```asm
CMP RAX, RBX
```

**Flags:** Reads the flags, does not change them.

### JNZ — branches when not zero

**Syntax:** `JNZ label`

Branches to the label when the last comparison indicated not zero. Flag condition: ZF = 0. When the condition is false, execution simply falls through to the next line.

**Flags:** Reads the flags, does not change them.

### JG — branches when greater (signed)

### JA — branches when above (unsigned)

**Syntax:** `JA label`

Branches to the label when the last comparison indicated above (unsigned). Flag condition: CF = 0 and ZF = 0. When the condition is false, execution simply falls through to the next line.

```asm
CMP RAX, RBX

```

**Flags:** Reads the flags, does not change them.

## Category: Call / return

Enters and leaves functions.

### CALL — calls a function

**Syntax:** `CALL destination`

Pushes the address of the next instruction (the return address) and branches to the function. The RET afterwards uses that value to come back.

```asm
CALL sum_values
CALL printf
```

**Flags:** Does not change flags.

### RET — returns from the function

**Syntax:** `RET  |  RET n`

Pops the return address and continues from there. The stack must be exactly as it was on entry, or the return goes to the wrong address.

```asm
RET
```

**Flags:** Does not change flags.

## Category: System

Talks to the kernel or to the hardware.

### SYSCALL — calls the kernel (Linux x86-64)

**Syntax:** `SYSCALL`

Hands control to the kernel. The service number goes in RAX and the arguments in RDI, RSI, RDX, R10, R8, R9. The return value comes back in RAX. RCX and R11 are destroyed.

```asm
MOV RAX, 1   ; write
MOV RDI, 1   ; stdout
MOV RSI, msg
MOV RDX, 13
SYSCALL
```

**Flags:** Does not change flags (RCX and R11 are overwritten).

### INT — raises a software interrupt

**Syntax:** `INT number`

INT 0x80 is the old 32-bit Linux system call — in 64-bit code the normal choice is SYSCALL. INT 3 is the breakpoint used by debuggers.

```asm
INT 0x80
INT 3
```

**Flags:** Depends on the handler.

### SYSENTER — fast kernel entry (32 bits)

**Syntax:** `SYSENTER`

Kernel entry mechanism on 32-bit systems. On x86-64 it was replaced by SYSCALL.

```asm
SYSENTER
```

**Flags:** —

### CPUID — identifies the processor

**Syntax:** `CPUID`

Returns CPU information in EAX/EBX/ECX/EDX according to the value previously placed in EAX.

```asm
XOR EAX, EAX
CPUID
```

**Flags:** Does not change flags.

### RDTSC — reads the cycle counter

**Syntax:** `RDTSC`

Places the number of cycles since reset in EDX:EAX. Used to measure time with high resolution.

```asm
RDTSC
```

**Flags:** Does not change flags.

### HLT — stops the processor

**Syntax:** `HLT`

Only makes sense in kernel/bare-metal code. In a user program it causes a protection fault.

```asm
HLT
```

**Flags:** —

## Category: Memory blocks

Copies, compares and fills whole regions.

### MOVSB — Move String byte

**Syntax:** `MOVSB  (usually REP MOVSB)`

Copies one byte from [RSI] to [RDI] and advances both. With REP and RCX it is a one-line memcpy.

```asm
MOV RCX, 100
REP MOVSB
```

**Flags:** Does not change flags. Direction controlled by DF (CLD/STD).

### STOSB — fills memory with AL

**Syntax:** `STOSB  (usually REP STOSB)`

Stores AL at [RDI] and advances RDI. With REP it becomes a memset.

```asm
XOR AL, AL
MOV RCX, 64
REP STOSB
```

**Flags:** Does not change flags.

### LODSB — loads a byte from [RSI] into AL

**Syntax:** `LODSB`

Loads one byte from [RSI] into AL and advances RSI. The basis for walking through strings.

```asm
LODSB
TEST AL, AL
JZ done
```

**Flags:** Does not change flags.

### SCASB — searches for a byte

**Syntax:** `SCASB  (usually REPNE SCASB)`

Compares AL with [RDI] and advances. With REPNE it finds a byte inside a buffer (the basis of strlen).

```asm
REPNE SCASB
```

**Flags:** Changes the comparison flags.

### CMPSB — compares two regions

**Syntax:** `CMPSB  (usually REPE CMPSB)`

Compares [RSI] with [RDI] and advances both. With REPE it is a memcmp.

```asm
REPE CMPSB
```

**Flags:** Changes the comparison flags.

### REP — repetition prefix

**Syntax:** `REP / REPE / REPNE instruction`

Repeats the string instruction RCX times. REPE stops when ZF=0; REPNE stops when ZF=1.

```asm
REP MOVSB
```

**Flags:** Depends on the repeated instruction.

### CLD — walk forward

**Syntax:** `CLD`

Clears DF: string instructions move forward (RSI/RDI increase). It is the state the ABI expects.

```asm
CLD
```

**Flags:** Clears DF.

### STD — walk backward

**Syntax:** `STD`

Sets DF: string instructions move backward. Always restore it with CLD afterwards.

```asm
STD
```

**Flags:** Sets DF.

### MOVSW — Move String word

**Syntax:** `MOVSW  (usually REP MOVSW)`

Copies one word (2 bytes) from the address in RSI to the address in RDI, then advances both registers by 2 (backwards when the direction flag is set). With the REP prefix it copies RCX words in one instruction — the fastest way to move a buffer, and the usual shape of a memory-copy payload.

```asm
MOV RCX, 100
REP MOVSB
```

**Flags:** Does not change flags. Direction controlled by DF (CLD/STD).

### MOVSD — Move String dword

**Syntax:** `MOVSD  (usually REP MOVSD)`

Copies one dword (4 bytes) from the address in RSI to the address in RDI, then advances both registers by 4 (backwards when the direction flag is set). With the REP prefix it copies RCX dwords in one instruction — the fastest way to move a buffer, and the usual shape of a memory-copy payload.

```asm
MOV RCX, 100
REP MOVSB
```

**Flags:** Does not change flags. Direction controlled by DF (CLD/STD).

### MOVSQ — Move String qword

**Syntax:** `MOVSQ  (usually REP MOVSQ)`

Copies one qword (8 bytes) from the address in RSI to the address in RDI, then advances both registers by 8 (backwards when the direction flag is set). With the REP prefix it copies RCX qwords in one instruction — the fastest way to move a buffer, and the usual shape of a memory-copy payload.

```asm
MOV RCX, 100
REP MOVSB
```

**Flags:** Does not change flags. Direction controlled by DF (CLD/STD).

### STOSW — Store String word

**Syntax:** `STOSW  (usually REP STOSW)`

Stores AX at the address in RDI and advances RDI by 2 (backwards when the direction flag is set). With REP it fills RCX words — how a buffer gets zeroed or filled in one go.

```asm
XOR AL, AL
MOV RCX, 64
REP STOSB
```

**Flags:** Does not change flags.

### STOSD — Store String dword

**Syntax:** `STOSD  (usually REP STOSD)`

Stores EAX at the address in RDI and advances RDI by 4 (backwards when the direction flag is set). With REP it fills RCX dwords — how a buffer gets zeroed or filled in one go.

```asm
XOR AL, AL
MOV RCX, 64
REP STOSB
```

**Flags:** Does not change flags.

### STOSQ — Store String qword

**Syntax:** `STOSQ  (usually REP STOSQ)`

Stores RAX at the address in RDI and advances RDI by 8 (backwards when the direction flag is set). With REP it fills RCX qwords — how a buffer gets zeroed or filled in one go.

```asm
XOR AL, AL
MOV RCX, 64
REP STOSB
```

**Flags:** Does not change flags.

### LODSW — Load String word

**Syntax:** `LODSW`

Loads one word (2 bytes) from the address in RSI into AX and advances RSI by 2 (backwards when the direction flag is set). Rarely useful with REP: each iteration would overwrite the previous value.

```asm
LODSB
TEST AL, AL
JZ done
```

**Flags:** Does not change flags.

### LODSD — Load String dword

**Syntax:** `LODSD`

Loads one dword (4 bytes) from the address in RSI into EAX and advances RSI by 4 (backwards when the direction flag is set). Rarely useful with REP: each iteration would overwrite the previous value.

```asm
LODSB
TEST AL, AL
JZ done
```

**Flags:** Does not change flags.

### LODSQ — Load String qword

**Syntax:** `LODSQ`

Loads one qword (8 bytes) from the address in RSI into RAX and advances RSI by 8 (backwards when the direction flag is set). Rarely useful with REP: each iteration would overwrite the previous value.

```asm
LODSB
TEST AL, AL
JZ done
```

**Flags:** Does not change flags.

### SCASW — Scan String word

**Syntax:** `SCASW  (usually REPNE SCASW)`

Compares AX with the word at the address in RDI, sets the flags and advances RDI by 2 (backwards when the direction flag is set). With REPNE it is the classic strlen/strchr loop: it scans until the byte matches or RCX runs out.

```asm
REPNE SCASB
```

**Flags:** Changes the comparison flags.

### SCASD — Scan String dword

**Syntax:** `SCASD  (usually REPNE SCASD)`

Compares EAX with the dword at the address in RDI, sets the flags and advances RDI by 4 (backwards when the direction flag is set). With REPNE it is the classic strlen/strchr loop: it scans until the byte matches or RCX runs out.

```asm
REPNE SCASB
```

**Flags:** Changes the comparison flags.

### SCASQ — Scan String qword

**Syntax:** `SCASQ  (usually REPNE SCASQ)`

Compares RAX with the qword at the address in RDI, sets the flags and advances RDI by 8 (backwards when the direction flag is set). With REPNE it is the classic strlen/strchr loop: it scans until the byte matches or RCX runs out.

```asm
REPNE SCASB
```

**Flags:** Changes the comparison flags.

### CMPSW — Compare String word

**Syntax:** `CMPSW  (usually REPE CMPSW)`

Compares the word at [RSI] with the word at [RDI], sets the flags and advances both registers by 2 (backwards when the direction flag is set). With REPE it compares RCX words — memcmp in one instruction.

```asm
REPE CMPSB
```

**Flags:** Changes the comparison flags.

### CMPSD — Compare String dword

**Syntax:** `CMPSD  (usually REPE CMPSD)`

Compares the dword at [RSI] with the dword at [RDI], sets the flags and advances both registers by 4 (backwards when the direction flag is set). With REPE it compares RCX dwords — memcmp in one instruction.

```asm

```

**Flags:** Changes the comparison flags.

### CMPSQ — Compare String qword

**Syntax:** `CMPSQ  (usually REPE CMPSQ)`

```asm
REPE CMPSB
```

**Flags:** Changes the comparison flags.

### REPNZ — repetition prefix

**Syntax:** `REP / REPE / REPNE instruction`

Repeats the string instruction RCX times. REPE stops when ZF=0; REPNE stops when ZF=1.

```asm
REP MOVSB
```

**Flags:** Depends on the repeated instruction.

### REPZ — repetition prefix

Real numbers and XMM registers.

### MOVSS — 32-bit float

**Syntax:** `MOVSS xmm, source`

Moves a single-precision float between XMM registers and memory.

```asm
MOVSS XMM0, [value]
```

**Flags:** Does not change flags.

### MOVSD_SSE — 64-bit double

**Syntax:** `MOVSD xmm, source`

Moves a double. Careful: the same MOVSD mnemonic also exists as a string instruction — the assembler decides from the operand.

```asm
MOVSD XMM0, [value]
```

**Flags:** Does not change flags.

### ADDSD — double addition

**Syntax:** `ADDSD xmm, source`

Adds two doubles in XMM registers.

```asm
ADDSD XMM0, XMM1
```

**Flags:** Does not change the integer flags.

### MULSD — Multiply Scalar Double

**Syntax:** `MULSD xmm, source`

Multiplies two doubles.

```asm
MULSD XMM0, XMM1
```

**Flags:** —

### CVTSI2SD — Convert Integer to Double

**Syntax:** `CVTSI2SD xmm, reg/mem`

Converts an integer to a double.

```asm
CVTSI2SD XMM0, RAX
```

**Flags:** —

## Category: Miscellaneous

Conversions, synchronization, no-ops.

### NOP — does nothing

**Syntax:** `NOP`

Burns one cycle. It is used to align code in memory and as placeholder space for patches.

```asm
NOP
```

**Flags:** Does not change flags.

### CDQ — extends EAX into EDX

**Syntax:** `CDQ`

Replicates the sign bit of EAX across EDX. Mandatory before a 32-bit IDIV.

```asm
CDQ
IDIV EBX
```

**Flags:** Does not change flags.

### CQO — extends RAX into RDX

**Syntax:** `CQO`

The 64-bit version of CDQ. Use it before IDIV with 64-bit operands.

```asm
CQO
IDIV RBX
```

**Flags:** Does not change flags.

### CWDE — Convert Word to Doubleword

**Syntax:** `CWDE`

Sign-extends AX into EAX.

```asm
CWDE
```

**Flags:** Does not change flags.

### BSWAP — reverses the byte order

**Syntax:** `BSWAP register`

Converts between little-endian and big-endian (network byte order).

```asm
BSWAP EAX
```

**Flags:** Does not change flags.

### XADD — swaps and adds (atomic with LOCK)

**Syntax:** `XADD destination, source`

Swaps the operands and stores the sum in the destination. The basis of atomic counters.

```asm
LOCK XADD [counter], RAX
```

**Flags:** Changes the arithmetic flags.

### CMPXCHG — the x86 CAS

**Syntax:** `CMPXCHG destination, source`

If destination == RAX, stores the source in the destination; otherwise loads the destination into RAX. The basis of locks and lock-free structures.

```asm
LOCK CMPXCHG [ptr], RBX
```

**Flags:** Changes ZF and the other arithmetic flags.

### LOCK — atomicity prefix

**Syntax:** `LOCK instruction`

Ensures the memory operation is atomic across cores.

```asm
LOCK INC [counter]
```

**Flags:** Depends on the instruction.

### ENDBR64 — marks a valid indirect branch target

**Syntax:** `ENDBR64`

Part of the CET/IBT protection. It marks that this address may be the target of an indirect call/jmp. Modern compilers place it at the start of every function.

```asm
ENDBR64
```

**Flags:** Does not change flags.

### UD2 — deliberate invalid instruction

**Syntax:** `UD2`

Raises an invalid opcode exception. Compilers use it to mark unreachable code.

```asm
UD2
```

**Flags:** —

## Flags (RFLAGS)

| Flag | Description |
| --- | --- |
| `ZF` | Zero — the result was exactly zero (or the compared values were equal). |
| `SF` | Sign — the highest bit of the result is 1 (negative number in signed interpretation). |
| `CF` | Carry — a carry-out or borrow happened. It is the flag used by unsigned branches (JA/JB). |
| `OF` | Overflow — the result went past the signed range. It is the flag used by signed branches (JG/JL). |
| `PF` | Parity — the low byte of the result has an even number of 1 bits. |
| `DF` | Direction — defines whether string instructions walk forward (0) or backward (1). |
